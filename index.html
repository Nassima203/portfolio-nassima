UWatch

Suivi de films & séries (en cours de développement)

Application web pour suivre les films et séries vus, à voir et la progression dans les saisons. Développée en React 19 + TypeScript strict avec Vite et Tailwind CSS, authentification OAuth Google/GitHub (PKCE) via Supabase avec routes protégées, et proxy serverless Vercel vers l'API TMDB pour garder le token côté serveur. Code testé avec Vitest et React Testing Library.

API de prise de rendez-vous

API REST en Python (FastAPI)

Conception d'une API pour réserver des rendez-vous chez un professionnel : consultation des créneaux libres, réservation, déplacement et annulation. Persistance SQLite via SQLModel, validation des données avec Pydantic (email, téléphone français, créneaux horaires), règles métier (créneau déjà pris refusé, modification impossible moins de 24 h avant) et erreurs uniformisées en français. Documentation interactive générée automatiquement et 13 tests automatisés avec pytest.
